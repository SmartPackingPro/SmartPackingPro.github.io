2. DESIGN SYSTEM
────────────────────────────────────────────────────────────────────────────

PATTERN    : App Store Style Landing + Scroll-Triggered Storytelling hybrid
STYLE      : Motion-Driven + Glassmorphism (dark hero, light body sections)
SOURCE     : UI/UX Pro Max skill — design system generated 2026-05-26

── Colours ──

  --primary        : #0EA5E9   (sky blue — trust, brand)
  --primary-dark   : #0284C7   (hover)
  --accent         : #F97316   (orange — CTA buttons, action)
  --accent-gold    : #FBBF24   (gold — stars, PRO badge, tips)
  --bg-hero        : #0A0E27   (deep navy — hero + dark sections)
  --bg-section     : #F0F9FF   (light sky — alternating body sections)
  --bg-card        : rgba(255,255,255,0.08)  (glassmorphism cards)
  --text-primary   : #0C4A6E   (body text, light sections)
  --text-on-dark   : #F0F9FF   (text on dark hero)
  --text-muted     : #475569   (captions, secondary)
  --border-glass   : rgba(255,255,255,0.15)  (glass card border)
  --green-success  : #22C55E   (ready badges, success states)

── Typography ──

  Font Family : Plus Jakarta Sans (Google Fonts)
  Import URL  : https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@300;400;500;600;700;800&display=swap
  
  Scales:
    Hero H1     : clamp(2.5rem, 6vw, 4.5rem)
    Section H2  : clamp(1.8rem, 4vw, 2.8rem)
    Feature H3  : clamp(1.1rem, 2vw, 1.4rem)
    Body        : 1rem (16px)
    Caption     : 0.875rem (14px)

── Effects ──

  Glassmorphism : backdrop-filter: blur(16px); background: rgba(255,255,255,0.08); border: 1px solid rgba(255,255,255,0.15)
  Scroll Reveal : Intersection Observer + opacity/translateY(30px) → 0
  Hover Lift    : transform: translateY(-4px); box-shadow with primary colour glow
  Float Device  : @keyframes float — 4s ease-in-out infinite, 12px Y travel
  Transitions   : 200–300ms ease (UI/UX Pro Max rule: never > 500ms)

── Icons ──

  Library : Lucide SVG (inline)
  Rule    : NO emoji as icons. All icons must be SVG from Lucide.
  Sizes   : 24×24 viewBox, consistent sizing per context

8. UI/UX RULES (from UI/UX Pro Max skill)
────────────────────────────────────────────────────────────────────────────

  ✗ NO emoji as icons → use Lucide SVG only
  ✗ NO layout shift on hover (use opacity/color, not scale)
  ✗ NO transitions > 500ms
  ✗ NO content hidden behind fixed navbar
  ✗ NO horizontal scroll on mobile
  ✓ cursor-pointer on ALL clickable elements
  ✓ Hover states: color/shadow change (150–300ms)
  ✓ Focus states visible (keyboard nav)
  ✓ prefers-reduced-motion respected (disable all animations)
  ✓ Images: alt text + WebP + loading="lazy"
  ✓ Responsive: 375px, 768px, 1024px, 1440px all tested
